# 🏨 Hotel Booking Confirmation Page — Frontend Mentor Solution

This is a solution to a **Frontend Mentor** challenge: a hotel booking confirmation page built with semantic HTML5, CSS custom properties, Flexbox, CSS Grid and a mobile-first workflow. It's enhanced with vanilla JavaScript interactions — a mobile menu toggle, copy-to-clipboard Wi-Fi password, print receipt, `.ics` calendar export and a card-fan visual.

## ✨ Features

- ✅ **Booking confirmation** layout with stay details, amenities and barcode
- 📋 **Copy Wi-Fi password** to clipboard (with legacy-browser fallback)
- 🖨️ **Print receipt** button using `window.print()`
- 📆 **Add to Calendar** — generates and downloads an `.ics` file with the booking details
- 🍔 **Animated mobile menu** with accessible `aria-expanded` state
- 🃏 **Card-fan interaction** for the booking card
- 🎨 Custom variable fonts — Fraunces, DM Sans and DM Mono (self-hosted)
- 📱 Mobile-first responsive design matching the provided Figma-style designs

## 🛠️ Tech Stack

- **Semantic HTML5**
- **CSS3** — custom properties, Flexbox, CSS Grid, mobile-first workflow
- **Vanilla JavaScript** — clipboard, print, `.ics` export, menu & card interactions
- **Self-hosted fonts** — Fraunces, DM Sans, DM Mono
